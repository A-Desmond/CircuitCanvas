# CircuitCanvas asset attribution

## Original assets

### ESP32 simplified 2D illustration

- Created for CircuitCanvas using React and CSS geometry.
- Based on the publicly documented ESP32-DevKitC V4 board layout and pin reference from Espressif.
- Reference: https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html

### ESP32 simplified procedural 3D model

- Created for CircuitCanvas using Three.js primitives.
- The model is intentionally educational rather than dimensionally exact.
- Reference: https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html

### LED, resistor, push button, breadboard, and jumper wires

- Original React/CSS and procedural Three.js geometry created for CircuitCanvas.
- No third-party product photos, copied vectors, textures, or 3D models are distributed.
